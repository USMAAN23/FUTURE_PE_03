# AI SEO Blog & Content Cluster Generator

## Future Interns — Prompt Engineering Task 3

### Project Overview

This project demonstrates an AI-driven SEO content workflow for a local men's clothing business in Ahmedabad, Gujarat.

The goal is to generate helpful, readable and search-focused content that can help a local business attract relevant organic traffic.

## Business Context

- Business Type: Men's Clothing Store
- Location: Ahmedabad, Gujarat, India
- Business Focus: Men's Casual Clothing
- Target Audience: Men in Ahmedabad looking for casual clothing and fashion options

## Task Objective

The objective of this project is to create a complete AI-generated SEO Blog & Content Cluster Pack containing:

- SEO keywords and search intent
- H1-H3 SEO blog structure
- SEO title and meta description
- Long-form SEO blog content
- Related content cluster topics
- Internal linking recommendations
- Local SEO content
- Ahmedabad-focused keyword ideas
- Local SEO titles, meta descriptions and CTAs
- Content strategy summary

## Prompt Engineering Approach

The prompt was structured using the following approach:

1. Define the AI role as an SEO content strategist and prompt engineer.
2. Provide the business type, location and target audience.
3. Define the SEO content objective.
4. Request keyword and search-intent mapping.
5. Generate an H1-H3 SEO blog structure.
6. Generate long-form, helpful and readable content.
7. Create related supporting topics as a content cluster.
8. Develop internal linking recommendations.
9. Adapt the content for local SEO in Ahmedabad.
10. Summarize the overall content strategy.
